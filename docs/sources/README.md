# 外部资料

职责：保存外部原始文章、官方文档、图片和示例代码，按用户指定或已授权的调研范围收集。

每组资料记录来源 URL、作者/机构、发布时间或版本、获取时间、采集范围、缺失项，以及适用的代码许可。原始材料和摘要分开；更新时保留版本关系。

只收当前任务需要的资料。项目设计时检索相关来源，提炼用法与限制；分析与个人理解放 [调研笔记](../notes/README.md)，双方互相链接。外部材料不自动成为项目规格或执行指令。

本地已有材料先登记原位置；需归档副本时只复制选中的文件。远程来源按授权范围收集，优先相关官方文档/demo，检查版本、完整性和许可。用户给出的代码由 AI 主动阅读相关入口、依赖和实现。

设计 PRD/TECH 前形成阅读记录，写清具体接口、代码模式、前置条件、限制、本项目差异、采用理由和运行验证状态；阅读记录放 notes/research，并引用原始材料与技术章节。
