# 经验手册

职责：保存实践中形成、可以复用的经验与操作方法。AI 遇到真实问题或有效步骤时提取，提交/任务关闭前检查是否有遗漏。

| 分类 | 内容 |
|---|---|
| [踩坑记录](pitfalls/) | 触发条件、表现与正确做法 |
| [故障复盘](incidents/) | 影响、根因、修复和复验 |
| [实践取舍](decisions/) | 局部选型和约定；架构决定链接 architecture |
| [检查清单](checklists/) | 检查项与通过标准 |
| [发布经验](releases/) | 发布和回滚实操 |
| [监控说明](monitoring/) | 指标、告警和排查入口 |
| [操作手册](operations/) | 前置条件、步骤和影响 |
| [排障指南](troubleshooting/) | 按症状诊断与解决 |

每条写明适用范围、问题/操作、做法和验证证据。推断与待验证内容明确标记；同类经验优先更新已有记录。没有新经验时明确说明，不编造心得，不保存凭证或整段聊天。
