# 英语作文分析：首版规格

## 依据与范围

用户提供两张照片作为功能参考：一张为英语作文原稿，另一张为分析报告。原稿照片包含题目要求、手写正文和教师批注；报告包含写作点评、逐句批改、个性化润色和佳句示例。照片中的姓名、班级、二维码等个人信息不复制进仓库，也不作为报告字段。

首版服务于英语作文。页面入口放在登录后工作台侧边栏“我的错题本”附近，并在工作台提供快捷入口。作文分析独立于普通作业错题分析：句子修改不自动写入 `mistakes`，也不计入知识图谱的错题次数。

## 用户流程

1. 上传 1～4 张作文原稿或题目要求照片；可补充年级和题目要求文字。提示用户上传前遮盖姓名、班级、二维码等信息。
2. 先识别题目要求与学生原文，标出看不清的词句。用户可编辑识别文本并确认，再请求分析。分析必须以确认后的原文为准，不把教师的批改笔迹当作学生写作内容。
3. 展示完整分析，保留原文对照；报告可在登录后再次查看。分析页面和历史列表只读取当前用户的记录。

## 报告内容

- REQ-E01 **写作点评**：分别评价内容覆盖、语言表达、篇章结构与书写可辨性。每项包含基于原文的证据、做得好的地方和下一步建议。看不清的书写不强行评分；没有明确评分标准时不生成总分或等级。
- REQ-E02 **逐句批改**：列出需要修改的原句、建议句、问题类型及简短原因；能确定的拼写、语法和标点问题与可选风格建议分开。不要无依据地改动人物、事件或原意。
- REQ-E03 **个性化润色**：选 2～3 处最有价值的改进，按“原句／润色句／为什么更好”呈现，可覆盖内容细节、句间衔接和语言表达。
- REQ-E04 **佳句参考**：可提供与题目相关的开头、过渡或结尾示例，明确标为参考表达。不要生成“班级金句”、班级排行、同学作品对比或虚构其他学生内容。
- REQ-E05 **识别不确定性**：识别不清的字词必须标记待核对；报告区分原文摘录、教师已有批注和 AI 建议。不得将推测的原文当作确定事实。
- REQ-E06 **权限与保存**：识别和生成均按现有 7 天试用规则限制；试用到期后仍可查看既有报告。只保存本人确认的题目、作文文字与报告，不长期保存照片。账号删除时清理报告记录。

## 实现边界

- 沿用现有 JPG／PNG／WEBP、单张不超过 8 MB、最多 4 张的限制。识别和分析建议分两步，以便用户先纠正手写识别结果；正式保存发生在用户确认并完成分析后。
- 新建作文报告数据表及追加式 D1 迁移；照片只在本次请求发送给 AI，服务端不写入 R2。新 API 必须复用 `authenticateForAi()`，历史读取使用 `authenticate()`，并按 `user_id` 限定所有读写。
- AI 结果仅供学习参考，关键语法判断和教师评分仍需人工核对。不得承诺提高分数或替代教师评价。

## 验收

- 可从照片识别英语作文，确认原文后得到四部分报告，且没有“班级金句”。
- 原文与逐句建议能够一一对照；模糊字词有清楚的待核对提示。
- 未登录、试用到期、跨账号访问、超限文件及无效格式均按现有接口规则处理。
- 桌面和手机页面可读；已有错题、练习卷和 Word 导出行为不受影响。

此规格对应当前开发分支；上线状态以合并和部署结果为准。
