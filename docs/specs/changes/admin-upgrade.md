# 管理后台升级实施范围

依据：[管理员后台升级交接文档](../../../管理员后台升级-交接文档.md)第 2、4 节。用户已要求继续完成剩余任务，并明确后台功能简洁清晰。

- REQ-001：五个独立入口，数据概览、用户管理、错题中心、上传批次、系统诊断。浅色布局、紧凑筛选与表格，手机导航横向排列。
- REQ-002：用户搜索、角色/状态筛选，新建/编辑/密码重置/启停/删除弹窗。密码一致性校验，保留服务端自锁保护与会话即时失效。
- REQ-003：错题分页查询，学科/用户/关键词筛选，多行内容查看编辑、单题删除。CSV/JSON 导出当前筛选全部分页，CSV 处理引号、换行与公式前缀。
- REQ-004：查看批次文件名、所属用户和题量；整批删除联动原图，先 R2 后 D1，失败保留索引便于重试。
- REQ-005：D1 连接延迟和表统计、R2 绑定、AI 配置及真实模型文本连通测试、会话密钥长度与请求头信任设置检查。
- REQ-006：build、lint、类型检查、真实本地 HTTP 权限/会话/CRUD 验证，以及桌面/手机浏览器验收。

## 边界

本次不改部署权限断言，不操作线上数据，不更改注册策略或引入新依赖。AI 连通测试为文本请求，不代表图片识别链路已完成验证。概览的 activeUsers 实际代表状态为 active 的启用账号，界面按真实口径命名。

## 实现与验收

[交付记录](../../delivery/features/admin-upgrade/feature.md)。实现采用原有 API 合约与 D1/R2；页面用原生 dialog 提供焦点约束和 Esc 关闭，提交期间禁止关闭，失败保留输入。
