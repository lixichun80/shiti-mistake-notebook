# 业务地图

先画清业务疆域，再分工开发。按实际角色端或业务领域建立 `01-分区/`，各分区下按页面/功能区建立 `01-模块/README.md`；数字前缀保持稳定排序。

- [站点总图](00-site-design.md)：全局角色、导航、流程、共享范围和跨分区依赖。
- [开发认领](ownership.md)：本次任务/工作流的职责与交接。

分区 README 说明角色、流程和模块列表。模块 README 说明职责、REQ、页面/路由、API 领域、规格章节、代码范围、依赖与验收入口，链接正式文档和任务，不复制整份规格。

正式文档见 [PRD/UI/TECH](../prds/)，执行记录见 [任务](../../delivery/features/)。共享文件和契约先明确负责人和依赖，目录隔离不等于没有冲突。
