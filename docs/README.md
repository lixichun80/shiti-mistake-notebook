# 项目知识库

根目录 [AGENTS.md](../AGENTS.md) 是项目入口。此目录保存可检索的项目知识；各模块 README 说明职责、更新时机和内容入口。

| 模块 | 回答什么 | 维护方式 |
|---|---|---|
| [需求规格](specs/README.md) | 给谁做、做什么、有效规格在哪里 | 人给意图，AI 协助整理 |
| [变更记录](changelog/README.md) | 改了什么、下一步是什么 | AI 根据实际变更维护 |
| [系统架构](architecture/README.md) | 系统如何连接、契约是什么 | AI 根据代码和配置维护 |
| [经验手册](experience/README.md) | 踩过什么坑、怎么操作和排查 | AI 从实践中提取 |
| [外部资料](sources/README.md) | 外部依据和原始材料是什么 | 按授权范围收集 |
| [调研笔记](notes/README.md) | 如何理解、还有什么想法 | 人工主导，AI 辅助 |

正式规格在 [初始规格](specs/prds/)、[变更方案](specs/changes/)、[下线方案](specs/retirement/)；交付记录在 [任务目录](delivery/features/)。模块索引记录有效版本与双向覆盖，不复制第二套正文。全部项目产物统一在 docs，根地图只导航。

提交实现改动与关闭任务前，检查变更记录、经验、规格差异和架构影响。未验证信息明确标记；无变化也要在任务进度中说明。初始化只建立结构，不代表知识内容已完善。

首次接入或新领域探索时填写 [冷启记录](notes/research/BOOTSTRAP.md)：人维护调研想法，AI 从代码、git 与可见实践记录提取上下文。设计前主动阅读相关 sources，提炼实际用法和限制，在技术方案中引用；存量项目只补当前任务所需缺口。
